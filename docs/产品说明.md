# Logic-Coloc 产品说明

## 一、一句话说清楚这是什么

**Logic-Coloc 是一个把「跨学科类比」从随口一说的联想，变成可计算、可验证、可留存的判断工具。**

你给它一段专业文本，它会告诉你：这个机制在其他学科里有没有结构上真正对应的东西——不是"听起来像"，而是把它拆成五个可量化的逻辑维度，算出相似度，超过阈值才承认。

五个功能模块共用一套内核：

| 模块 | 一句话职责 |
|---|---|
| **求知** | 理解文本，找出跨学科同源，或把专业内容翻译成大白话 |
| **卡片** | 把知识沉淀成"正面概念 / 背面解释"的卡片，按书本归类 |
| **复习** | 用闪卡自测，把"看过"变成"掌握" |
| **笔记** | 完整的个人知识流：富文本、分类、附件、模板 |
| **看山** | 个人主页与成长体系：能量、等级、学习记录 |

## 二、它到底解决了什么问题

跨学科类比是人类最有效的理解方式之一，但它有两个老毛病：

**一是没法验证。** "免疫系统和服务器负载均衡很像"——这话对不对？像在哪儿？边界在哪？传统上只能靠直觉和权威判断，不同的人可以给出完全相反的结论。

**二是没法沉淀。** 读到一个精彩的类比，通常就止步于"哦，有意思"。下次遇到相关问题，想不起来，也找不到。

Logic-Coloc 的做法是把类比拆开、算出来、存下来。

### 核心思路：把文本压成"逻辑画像"

系统定义五个正交的逻辑维度，每维打 0–100 分：

- **系统封闭性**——自包含、闭环运行的程度
- **因果链长度**——从起因到结果要经过几环
- **负反馈强度**——自我抑制、纠错、防失控的能力
- **随机性 / 熵值**——过程里的不确定成分
- **资源零和性**——竞争、守恒、此消彼长的程度

一段文本进来，先被压成这五个数字组成的向量。两段文本的"同源度"就是这两个向量的余弦相似度——**这一步完全在本地计算，不经过任何大模型**。

这个分工是刻意的：**大模型只负责"理解文本"，不负责"下判断"。** 如果让模型既理解又裁决，它的结论既不可复现、也无法审计。现在模型打分被固定成 JSON 输出，判定则由确定性的数学完成——同样的输入永远得到同样的分数，每一个分数都能拆开看是哪一维贡献的。

### 一条被反复强调的原则

界面上固定显示一句话：**「底层逻辑相似 ≠ 科学等价」**。

系统找到的是**结构对应关系**，不是科学等价性。负反馈在免疫系统里靠抗体浓度实现，在服务器里靠请求队列实现——**机制角色相似，实现材料和成立边界完全不同**。所以每个同源结论都会附带成立条件、来源引用和失效边界，而不是给一个光秃秃的相似度数字。

## 三、五个功能模块

### 3.1 求知（核心）

底栏正中间那个，是整个 App 的入口。分两个模式：

**跨学科理解**——输入一个概念或一段文本，系统做三件事：

1. 在策展知识库（当前 11 个跨学科概念）里检索候选
2. 对每个候选计算五维逻辑画像的同源度
3. 同源度超过阈值的候选，才继续生成术语映射、学习报告和批判性评审

低于阈值的候选**不会被隐藏**——分数和理由照常展示，只是不往下展开。这是为了让人看到"为什么不匹配"，而不是被一个沉默的过滤器挡住。

结果会返回最多 3 个可展开模块，每个都包含：机制对照、术语一一映射、跨域学习报告、以及一份对报告本身的可靠性评审。

**读懂它**——把专业段落翻译成你能理解的语言，并给出这段文本的逻辑画像。解答完之后可以**连续追问**，系统记得住上下文。

**三种导入方式**：从链接导入（知乎、小红书、抖音分享链接）、手动粘贴、从截图导入（自动 OCR 识字）。

无论是哪个模式，结果都可以一键**「存为卡片」**——这是"求知"流向"复习"的管道。

### 3.2 卡片

知识沉淀的容器，三层结构：**书架 → 书本 → 卡片**。

每张卡片是"正面概念 / 背面解释"，正反面都可以插图。卡片带掌握状态（待复习 / 已掌握），点开任意一张可以编辑或删除。系统预置了三本书（Agent 探索、跨学科机制、系统科学）共 5 张示例卡片，开箱即可体验复习流程。

### 3.3 复习

闪卡（flashcard）自测，按"未掌握 / 已掌握 / 全部"筛选。

复习流程有个**防"假性掌握"的设计**，这是它和普通背单词软件最大的区别：

1. **先自评**——看到正面，在「认识 / 模糊 / 忘记了」里选一个。**此时答案还扣着不给看。**
2. **再翻面**——看到背面的解释。
3. **最后确认**——翻面之后你还可以推翻自己：选「下一词」或「记错了」。

**只有「认识」+「下一词」双重确认，才判定为已掌握**（+10 能量）。选了"模糊""忘记了"，或者翻面后改口"记错了"，卡片都会**放回本轮队尾**，这轮再来一次。

这个设计的价值在于：人在看到答案之前和之后，对自己"会不会"的判断常常是相反的。把两次判断分开，并且只承认一致的、经得起答案检验的那次，掌握状态才有意义。

选"模糊"或"忘记了"的卡片会被标记为"困难"，复习结束页会给出本次统计：复习了几张、掌握了几张、模糊遗忘几张。

已有卡片的掌握状态可以重置，也可以批量管理（删除、移出已掌握）。

### 3.4 笔记

一个完整的个人知识流，不只是个输入框：

- **组织**：分类文件夹、搜索、列表 / 网格双布局、批量管理（分享、导出、移动、删除、全选）
- **编辑器**：富文本。字体（10 种）、字号、粗体 / 斜体 / 下划线、文字颜色、背景高亮、有序 / 无序列表、插入图片
- **模板**：新建笔记时可选封面（支持自定义上传）+ 6 种纸张样式（空白 / 宽横格 / 窄横格 / 点阵 / 小格纹 / 中格纹）+ 3 种纸张颜色（白 / 米黄 / 黑）
- **附件**：支持图片与 PDF，内置预览
- **整理**：笔记可重命名、移动文件夹、删除；文件夹可重命名、换封面、删除（删除后内部笔记自动移回根目录）

### 3.5 看山

个人主页 + 成长体系，名字取自"看山是山，看山不是山，看山还是山"的三重境界。最高等级叫**「刘看山首席研究员」**。

**等级体系**（能量制，5 级）：

| 等级 | 称号 | 能量区间 | 阶段主题 |
|---|---|---|---|
| LV.1 | 学术萌新 | 0–99 | 建立习惯 |
| LV.2 | 知识学徒 | 100–299 | 积累知识 |
| LV.3 | 科研助手 | 300–499 | 辅助研究 |
| LV.4 | 探索达人 | 500–999 | 跨域探索 |
| LV.5 | 刘看山首席研究员 | 1000+ | 持续创造 |

**能量从哪来**——9 种学习行为，每种都有对应的反馈文案：

| 行为 | 能量 | 反馈 |
|---|---|---|
| 每日登录 | +3 | 揉揉眼睛醒来，获得今日口粮 |
| 读懂新概念 | +10 | 头顶冒出小灯泡 |
| 深入追问（达 3 次） | +5 | 戴上小眼镜陪你钻研 |
| 发现跨学科同源 | +15 | 拿到放大镜，找到逻辑宝藏 |
| 存为知识卡片 | +5 | 把知识果实放进小背包 |
| 复习考核掌握 | +10 | 开心转圈圈，播撒星星 |
| 复习考核遗忘 / 模糊 | +2 | 拍拍你，"没关系，再来一次" |
| 新建笔记 | +10 | 在纸上画下你的思考轨迹 |
| 整理书架 / 新建书籍 | +5 | 整理书架，成就感满满 |

注意「复习考核遗忘 / 模糊」也**给 2 分**——答错不惩罚，只做鼓励。这是刻意的：复习的敌人是"不敢开始"，不是"答错"。

页面还会展示**我的记录**：已掌握卡片数、未掌握卡片数、笔记数量、学习天数。升级时会有进度条动画和 toast 提示。另有独立的「规则与明细」页完整列出等级与积分规则。

## 四、一次完整的使用动线

五个模块不是并列的，它们串成一条闭环：

```
求知（读懂 / 发现同源）
   ↓  存为卡片
卡片（书架分类沉淀）
   ↓
复习（双重确认式自测）
   ↓  掌握 +10 能量
看山（等级成长、记录累积）
   ↓  产生新的求知欲望
笔记（全程可随时记录思考）
```

**求知负责"输入与理解"，卡片负责"沉淀"，复习负责"内化"，看山负责"反馈与坚持"，笔记负责"自由记录"。** 一个知识从"读到"到"掌握"的完整路径被这五个模块覆盖了。

## 五、技术上的三个关键设计

**1. 判定权和大模型解耦。**
大模型只做特征提取（把文本变成五维向量），所有评分、检索、阈值判定都在本地确定性完成。好处是：结果可复现、可审计、可解释——每个分数都能拆开看是哪一维贡献的，而不是一个黑箱给出的数字。

**2. 本地优先（local-first）的数据策略。**
卡片、笔记、复习进度、能量、历史记录全部先存在浏览器本地，服务端同步是**可选的增强**而不是前置条件。断网时整个 App 仍然可用，只是不跨设备。界面上会明确标注「[本地暂存]」状态，不制造"已同步"的假象。

**3. 不可靠时宁可不说。**
同源度不到阈值，就不生成映射和报告，只展示分数；候选全部低于检索门槛，就返回空列表并显示「当前证据不足，不强行建立类比」，而不是硬凑一个答案出来。

## 六、当前阶段的边界

**知识库规模**：策展语料当前为 11 个跨学科概念，这是保证演示质量的规模，不是检索能力的上限。语料中每个概念的逻辑画像是**人工标定的**，不是模型自动生成的。

**数据存储**：卡片、笔记等数据存在浏览器本地，换设备或清空浏览器数据会丢失。服务端已具备笔记与卡片的保存接口，同步链路正在接入中。

**三个功能的接口尚未接通**，目前在界面上会给出友好提示并降级到本地保存，不影响其他功能使用：

- **从链接导入**——前端已能识别并提取分享链接，但后端的链接解析服务尚未实现，当前会提示"该链接被平台限制，解析失败"并自动引导到截图导入
- **头像上传**——降级为保存在本机
- **昵称 / 签名同步**——降级为保存在本机

**会话状态**：服务端的对话会话保存在进程内存中，服务重启后历史会话失效。界面上的"历史记忆"保存在浏览器本地，不受影响。

**单次分析耗时**：跨学科同源发现需要多次调用大模型做采样与报告生成，单次约需 70 秒。这是为了保证打分稳定性的设计取舍，不是性能缺陷。
